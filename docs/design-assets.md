# Visual assets

The portal mark and six professor avatars are original SVG illustrations for this project. The mark is a portal identity, not an official university seal. Avatars represent fictional sample profiles.

Campus images illustrate a fictional university and do not depict Kyungdong University. The frontend labels them as illustrative.

Files: frontend/public/assets/kdu-mark.svg, campus-detail.svg, campus-hero.webp (1600px), campus-hero-small.webp (800px), avatars/professor-1.svg through professor-6.svg. The WebP copies are optimized for the frontend.
